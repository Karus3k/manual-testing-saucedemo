# manual-testing-saucedemo

Manual testing practice on SauceDemo (https://www.saucedemo.com), a demo shop made for testers.

What's here:
- `test-plan.md` - what I test and how
- `test-cases.md` - test cases with results
- `bug-reports/` - bugs I found

The site has a few test users. `problem_user` and `error_user` have bugs on purpose, so it's good for practicing bug reports.

Tools: Chrome, Chrome DevTools, Markdown on GitHub.

Status: in progress.
